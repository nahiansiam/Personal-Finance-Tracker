<h1>💰 Personal Finance Tracker (Python Project)</h1>

<p>
A simple Personal Finance Tracker built using Python, SQLite, Pandas, and Matplotlib.
This project helps users manage their daily income and expenses efficiently.
It also provides visual insights using charts and reports.
</p>

<h2>🚀 Features</h2>

<ul>
  <li>Add Income</li>
  <li>Add Expense</li>
  <li>View All Transactions</li>
  <li>Calculate Total Income & Expense</li>
  <li>Balance Calculation</li>
  <li>Monthly Financial Report</li>
  <li>Category-wise Expense Analysis</li>
  <li>Pie Chart Visualization</li>
  <li>Bar Chart Visualization</li>
  <li>Export Data to CSV</li>
</ul>

<h2>🛠️ Technologies Used</h2>

<ul>
  <li>Python</li>
  <li>SQLite (Database)</li>
  <li>Pandas (Data Analysis)</li>
  <li>Matplotlib (Data Visualization)</li>
  <li>Jupyter Notebook</li>
</ul>

<h2>📊 Project Goal</h2>

<p>
This project is designed for beginners to understand how to build a real-world data project using Python.
It demonstrates database handling, data analysis, and visualization in one notebook.
</p>
